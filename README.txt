----------------------------HOSTEL MANAGEMENT SYSTEM--------------------------------

In order to run the website on your system:
1. Install XAMPP
2. Copy the complete project folder inside C:\xampp\htdocs.
3. Start the xampp server.
4. In your browser, go to localhost/phpmyadmin.
5. Import the file hostelmsphp.sql in the DATABASE FILE folder to set up the website database.
6. Then go to http://localhost/HostelManagement-PHP/ to run the website.
